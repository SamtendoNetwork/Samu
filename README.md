# **Samu - Wii U emulator**

Custom fork of Cemu for supporting Wii U. This is not officially supported by all Samtendo services, and may not work on some.

Samu is currently only available for 64-bit Windows, Linux & macOS devices.

### Links:
 - [Official Discord](https://discord.gg/samtendo)
 - [Setup Guide](https://cemu.cfw.guide)

## Download

You can download the latest Samu releases for Windows, Linux and Mac from the [GitHub Releases](https://github.com/SamtendoNetwork/Samu/releases/).

On Windows, Samu is available both as an installer and in a portable format, where no installation is required besides extracting it in a safe place.

The native macOS build is currently purely experimental and should not be considered stable or ready for issue-free gameplay. There are also known issues with degraded performance due to the use of MoltenVK and Rosetta for ARM Macs. We appreciate your patience while we improve Samu for macOS.

## Build Instructions

To compile Samu yourself on Windows, Linux or macOS, view [BUILD.md](/BUILD.md).
